# Caja Link Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Caja Link interoperability service (FESC Legacy Challenge 2026, nivel Profesional) that answers affiliation-status queries across 4 heterogeneous "cajas de compensación" (REST, SOAP, flat-file, config-activated 4th), with auth, purpose-based access control, data minimization, fault tolerance, idempotent batch processing at 10k-document scale, auditing, and versioning — scored 70% by an automated validator and 30% by verifiable documents (ADRs, threat model proven by tests, load test, OpenAPI, README).

**Architecture:** Hub-central pattern. One FastAPI service (`caja-link`, port 8083) holds one adapter per caja behind a common `CajaAdapter` interface; an orchestrator fans out to all adapters except the requesting caja in parallel (`asyncio.gather`, per-adapter timeout), and builds the aggregate result (`AFILIADO_OTRA_CAJA` / `NO_AFILIADO` / `INDETERMINADO`) from the raw lookups. Response schemas are built field-by-field from Pydantic models (never a pass-through of a caja's raw JSON/XML), so data minimization is a property of the schema, not a filter someone can forget.

**Tech Stack:** Python 3.12, FastAPI, httpx (async client, shared/pooled), Pydantic v2, PyYAML, pytest + requests (black-box contract tests), Docker Compose.

**Spec:** `RETO.md` §6 + `KIT.md` + `RUBRICA.md` (nivel Profesional) — the organizers' contract, binding and already in the repo root. Internal architecture decisions: `docs/superpowers/specs/2026-10-13-caja-link-architecture.md`.

## Global Constraints

- Service listens on port **8083** exactly; routes, field names and enum values in `RETO.md` §6 are verbatim and mandatory (the validator string-matches them).
- No file under `src/` may contain the literal strings `caja-norte`, `caja-oriente`, `caja-sur`, `:9001`, `:9002`, `:9004` (automatic penalty, scanned as plain text — comments included). All connection details come from `.env` / `config/cajas.yaml`.
- No service of ours may mount `./mocks` or read `mocks/data/*.json` directly (automatic penalty). We talk to Norte/Oriente/Sur only via their published REST/SOAP interface, and to Centro only via its published daily flat file.
- `.env` is never committed (already in `.gitignore`); no literal secret value appears in any other file.
- `docker-compose.yml` additions may not use `privileged`, `cap_add`, `devices`, `network_mode: host`, `pid: host`, or mount anything outside the repo.
- Every response field name matches the contract exactly: `requestId`, `result`, `matches` (`caja`, `validFrom`, `validTo`, `source`, `asOf`), `unavailable`, `affiliateType` (v2 only), `jobId`, `status`, `results`, audit's `timestamp`/`requestingCaja`/`purpose`/`result`/`documentMasked`.
- Commit messages ≥3 words, never from the generic list (`update`, `fix`, `wip`, `cambios`, `commit`, `test`, `ok`, `listo`, `avance`, `save`, `initial commit`...). Both teammates commit under their own name/email, ≥3 commits each, ≥10 total.
- Documents are compared by canonical form (digits only, no leading zeros) regardless of dots/spaces/zero-padding in the input.

## Review Focus

1. **A caja that times out mid-batch, not just mid-single-query** — the spec's fault-tolerance rule ("nunca responde NO_AFILIADO" si no se pudo consultar) applies per-document inside the 10k-document batch too, not only to the single-query endpoint. Task 10's batch processor must reuse the exact same aggregation path as v1, not a simplified copy.
2. **Oriente's 12-digit zero-padding both ways** — a document that is naturally fewer than 12 digits must be padded when calling Oriente, and Oriente's zero-padded reply must normalize back down to match Norte/Sur/Centro's un-padded form, or P04 (normalization) silently breaks only for the Oriente match.
3. **A caja responding 200 with an empty/not-found body is not the same as a caja being unavailable** — "no encontrado" must count as a normal, available response (contributes to `NO_AFILIADO` only if nothing else matches), not get lumped into `unavailable`. Getting this backwards fails P07 by making every query `INDETERMINADO`.
4. **Idempotency-Key reuse with the batch still running** — a second POST with the same key while the first job is still `RUNNING` must return the same `jobId` without starting a second concurrent run against the cajas (duplicate load, duplicate audit entries).
5. **The admin token must never satisfy a caja-token check and vice versa** — `requester_from_token` must not accidentally match `ADMIN_TOKEN` as a valid "requesting caja" (which would let the admin token impersonate a caja and bypass the exclusion-from-matches rule, P05).

```python
# src/documents.py
import re

_NON_DIGITS = re.compile(r"\D")


def normalize(raw: str) -> str:
    """Forma canónica de un documento: solo dígitos, sin ceros a la izquierda.

    Tolera puntos, espacios y relleno con ceros (Caja Oriente usa 12 dígitos con
    ceros a la izquierda; las demás no), de forma que la misma persona compare
    igual sin importar cómo llegó el documento.
    """
    digits = _NON_DIGITS.sub("", raw or "")
    stripped = digits.lstrip("0")
    return stripped or ("0" if digits else "")


def to_oriente_format(document: str) -> str:
    """Caja Oriente exige exactamente 12 dígitos con ceros a la izquierda."""
    return document.zfill(12)


def mask(document: str) -> str:
    """Enmascara un documento dejando como máximo los 4 últimos dígitos visibles."""
    if len(document) <= 4:
        return "*" * len(document)
    return "*" * (len(document) - 4) + document[-4:]
```

```python
from dataclasses import dataclass, field
from datetime import date
from enum import Enum
from typing import Optional, Tuple


class AffiliateType(str, Enum):
    DEPENDIENTE = "DEPENDIENTE"
    INDEPENDIENTE = "INDEPENDIENTE"
    PENSIONADO = "PENSIONADO"


@dataclass(frozen=True)
class Membership:
    valid_from: date
    valid_to: Optional[date]
    affiliate_type: AffiliateType

    def is_active(self, as_of: date) -> bool:
        return self.valid_to is None or self.valid_to >= as_of


@dataclass(frozen=True)
class CajaLookup:
    """Resultado de preguntarle a una caja por un documento. Interno: nunca se
    serializa tal cual hacia la API (eso lo hace el orquestador, construyendo
    los modelos de schemas.py campo por campo)."""

    caja: str
    available: bool
    memberships: Tuple[Membership, ...] = field(default_factory=tuple)
    source: str = "ONLINE"  # "ONLINE" | "FILE"
    as_of: Optional[date] = None  # solo relevante cuando source == "FILE"
```

```python
    NO_AFILIADO = "NO_AFILIADO"
    INDETERMINADO = "INDETERMINADO"

    ONLINE = "ONLINE"
    FILE = "FILE"


class AffiliationMatchV1(BaseModel):
    caja: str
    validFrom: date
    validTo: Optional[date] = None
    source: FuenteMatch
    asOf: date


class AffiliationMatchV2(AffiliationMatchV1):
    affiliateType: str

    requestId: str
    result: ConsultaResultado
    matches: List[AffiliationMatchV1] = Field(default_factory=list)
    unavailable: List[str] = Field(default_factory=list)

    requestId: str

    matches: List[AffiliationMatchV2] = Field(default_factory=list)
    unavailable: List[str] = Field(default_factory=list)

    requestingCaja: str
    purpose: str
```

```python
# src/config.py
import os
from dataclasses import dataclass
from pathlib import Path
from typing import Dict, Tuple

import yaml

DEFAULT_CONFIG_PATH = Path(os.environ.get("CAJAS_CONFIG_PATH", "config/cajas.yaml"))


@dataclass(frozen=True)
class CajaDeclaration:
    nombre: str
    adaptador: str


@dataclass(frozen=True)
class Settings:
    tokens: Dict[str, str]
    norte_url: str
    norte_api_key: str
    oriente_url: str
    oriente_user: str
    oriente_password: str
    centro_dir: Path
    sur_url: str
    sur_token: str
    sur_enabled: bool
    cajas_declaradas: Tuple[CajaDeclaration, ...]

    @classmethod
    def load(cls, config_path: Path = DEFAULT_CONFIG_PATH) -> "Settings":
        with open(config_path, encoding="utf-8") as handle:
            raw = yaml.safe_load(handle) or {}
        declaradas = tuple(CajaDeclaration(**item) for item in raw.get("cajas", []))

        def env(name: str, default: str = "") -> str:
            return os.environ.get(name, default)

        return cls(
            tokens={
                "NORTE": env("NORTE_TOKEN"),
                "ORIENTE": env("ORIENTE_TOKEN"),
                "CENTRO": env("CENTRO_TOKEN"),
                "SUR": env("SUR_TOKEN"),
                "ADMIN": env("ADMIN_TOKEN"),
            },
            norte_url=env("CAJA_NORTE_URL"),
            norte_api_key=env("CAJA_NORTE_API_KEY"),
            oriente_url=env("CAJA_ORIENTE_URL"),
            oriente_user=env("CAJA_ORIENTE_USER"),
            oriente_password=env("CAJA_ORIENTE_PASSWORD"),
            centro_dir=Path(env("CAJA_CENTRO_DIR", "/data/caja-centro")),
            sur_url=env("CAJA_SUR_URL"),
            sur_token=env("CAJA_SUR_TOKEN"),
            sur_enabled=env("CAJA_SUR_ENABLED", "false").lower() == "true",
            cajas_declaradas=declaradas,
        )
```

```python
import logging
from datetime import date, datetime
from xml.etree import ElementTree as ET

import httpx

from .base import CajaAdapter
from .models import AffiliateType, CajaLookup, Membership
from ..documents import to_oriente_format

logger = logging.getLogger(__name__)

_SOAP_NS = "http://schemas.xmlsoap.org/soap/envelope/"
_ORI_NS = "http://cajaoriente.example/afiliacion"
_TIPO_MAP = {"D": AffiliateType.DEPENDIENTE, "I": AffiliateType.INDEPENDIENTE, "P": AffiliateType.PENSIONADO}


def _envelope(user: str, password: str, documento_12: str) -> str:
    return (
        '<?xml version="1.0" encoding="UTF-8"?>'
        f'<soapenv:Envelope xmlns:soapenv="{_SOAP_NS}" xmlns:ori="{_ORI_NS}">'
        f"<soapenv:Header><ori:Credenciales><ori:Usuario>{user}</ori:Usuario>"
        f"<ori:Clave>{password}</ori:Clave></ori:Credenciales></soapenv:Header>"
        "<soapenv:Body><ori:ConsultarAfiliacionRequest>"
        f"<ori:NumeroDocumento>{documento_12}</ori:NumeroDocumento>"
        "</ori:ConsultarAfiliacionRequest></soapenv:Body></soapenv:Envelope>"
    )


def _parse_fecha(value: str) -> date:
    return datetime.strptime(value, "%d/%m/%Y").date()


class OrienteAdapter(CajaAdapter):
    name = "ORIENTE"

    def __init__(self, client: httpx.AsyncClient, base_url: str, user: str, password: str, timeout: float = 2.5):
        self._client = client
        self._base_url = base_url
        self._user = user
        self._password = password
        self._timeout = timeout

    async def lookup(self, document: str) -> CajaLookup:
        payload = _envelope(self._user, self._password, to_oriente_format(document))
        try:
            response = await self._client.post(
                self._base_url,
                content=payload.encode("utf-8"),
                headers={"Content-Type": "text/xml; charset=utf-8", "SOAPAction": "ConsultarAfiliacion"},
                timeout=self._timeout,
            )
        except httpx.HTTPError:
            logger.warning("Caja Oriente no disponible consultando %s", document)
            return CajaLookup(caja=self.name, available=False)

        try:
            root = ET.fromstring(response.text)
        except ET.ParseError:
            logger.warning("Caja Oriente devolvio XML invalido")
            return CajaLookup(caja=self.name, available=False)

        if root.find(f".//{{{_SOAP_NS}}}Fault") is not None:
            logger.warning("Caja Oriente devolvio SOAP Fault (credenciales o formato)")
            return CajaLookup(caja=self.name, available=False)

        if root.findtext(f".//{{{_ORI_NS}}}Encontrado") != "true":
            return CajaLookup(caja=self.name, available=True, memberships=())

        memberships = []
        for afiliacion in root.iterfind(f".//{{{_ORI_NS}}}Afiliacion"):
            retiro = afiliacion.findtext(f"{{{_ORI_NS}}}FechaRetiro")
            memberships.append(
                Membership(
                    valid_from=_parse_fecha(afiliacion.findtext(f"{{{_ORI_NS}}}FechaIngreso")),
                    valid_to=_parse_fecha(retiro) if retiro else None,
                    affiliate_type=_TIPO_MAP[afiliacion.findtext(f"{{{_ORI_NS}}}TipoAfiliado")],
                )
            )
        return CajaLookup(caja=self.name, available=True, memberships=tuple(memberships))
```

```python
import logging
import re
from datetime import date
from pathlib import Path
from typing import Optional

from .base import CajaAdapter
from .models import AffiliateType, CajaLookup, Membership

logger = logging.getLogger(__name__)

_TIPO_MAP = {"DEP": AffiliateType.DEPENDIENTE, "IND": AffiliateType.INDEPENDIENTE, "PEN": AffiliateType.PENSIONADO}
_FILENAME = re.compile(r"^centro_afiliados_(\d{8})\.txt$")


def _parse_fecha(value: str) -> date:
    return date(int(value[0:4]), int(value[4:6]), int(value[6:8]))


class CentroAdapter(CajaAdapter):
    """Caja Centro no tiene servicio en vivo: lee el archivo plano diario mas
    reciente del directorio publicado (nunca mocks/data)."""

    name = "CENTRO"

    def __init__(self, directory):
        self._directory = Path(directory)

    def _latest_file(self) -> Optional[Path]:
        if not self._directory.is_dir():
            return None
        candidates = sorted(
            (p for p in self._directory.glob("centro_afiliados_*.txt") if _FILENAME.match(p.name)),
            key=lambda p: _FILENAME.match(p.name).group(1),
        )
        return candidates[-1] if candidates else None

    async def lookup(self, document: str) -> CajaLookup:
        path = self._latest_file()
        if path is None:
            logger.warning("Caja Centro: no hay archivo centro_afiliados_*.txt en %s", self._directory)
            return CajaLookup(caja=self.name, available=False)

        as_of: Optional[date] = None
        found: Optional[Membership] = None
        with path.open(encoding="utf-8") as handle:
            for raw_line in handle:
                line = raw_line.strip()
                if not line or line.startswith("TIPO_DOC|"):
                    continue
                if line.startswith("FECHA_CORTE|"):
                    as_of = _parse_fecha(line.split("|", 1)[1])
                    continue
                fields = line.split("|")
                if len(fields) < 7:
                    continue
                _, numero_documento, fecha_inicio, fecha_fin, tipo_afiliado = fields[:5]
                if numero_documento.lstrip("0") != document.lstrip("0"):
                    continue
                found = Membership(
                    valid_from=_parse_fecha(fecha_inicio),
                    valid_to=_parse_fecha(fecha_fin) if fecha_fin else None,
                    affiliate_type=_TIPO_MAP[tipo_afiliado],
                )

        return CajaLookup(
            caja=self.name,
            available=True,
            memberships=(found,) if found else (),
            source="FILE",
            as_of=as_of,
        )
```

```python
from typing import List

import httpx

from ..config import Settings
from .base import CajaAdapter

            continue
        adapters.append(_BUILDERS[declaracion.adaptador](client, settings))
    return adapters
```

```python
async def _agregar(document: str, requester: str, adapters: Sequence[CajaAdapter], today: date) -> _Agregado:
    relevantes = [a for a in adapters if a.name != requester]
    lookups = await asyncio.gather(*(_safe_lookup(a, document) for a in relevantes))

    matched: List[Tuple[CajaLookup, Membership, date]] = []
    unavailable: List[str] = []
    for lookup in lookups:
        if not lookup.available:
            unavailable.append(lookup.caja)
            continue
        as_of = lookup.as_of if lookup.source == "FILE" and lookup.as_of else today
        for membership in lookup.memberships:
            if membership.is_active(as_of):
                matched.append((lookup, membership, as_of))

    if matched:
        result = ConsultaResultado.AFILIADO_OTRA_CAJA
    elif unavailable:
        result = ConsultaResultado.INDETERMINADO
    else:
        result = ConsultaResultado.NO_AFILIADO
    return _Agregado(result=result, unavailable=unavailable, matched=matched)


async def consultar_v1(
    document: str, requester: str, adapters: Sequence[CajaAdapter], today: Optional[date] = None
) -> AffiliationResponseV1:
    agregado = await _agregar(document, requester, adapters, today or date.today())
    matches = [
        AffiliationMatchV1(
            caja=lookup.caja,
            validFrom=membership.valid_from,
            validTo=membership.valid_to,
            source=FuenteMatch(lookup.source),
            asOf=as_of,
        )
        for lookup, membership, as_of in agregado.matched
    ]
    return AffiliationResponseV1(
        requestId=str(uuid.uuid4()), result=agregado.result, matches=matches, unavailable=agregado.unavailable
    )


async def consultar_v2(
    document: str, requester: str, adapters: Sequence[CajaAdapter], today: Optional[date] = None
```

```python
# src/security.py
from typing import Optional

from fastapi import Depends, Header, HTTPException, Request

from .config import Settings

VALID_PURPOSES = {"TARIFA_SUBSIDIADA", "SUBSIDIO_MONETARIO", "VALIDACION_AFILIACION"}


def get_settings(request: Request) -> Settings:
    return request.app.state.settings


def requester_from_token(
    authorization: Optional[str] = Header(default=None), settings: Settings = Depends(get_settings)
) -> str:
    if not authorization or not authorization.startswith("Bearer "):
        raise HTTPException(status_code=401, detail="Falta token Bearer")
    token = authorization.removeprefix("Bearer ").strip()
    for caja, expected in settings.tokens.items():
        if caja != "ADMIN" and expected and token == expected:
            return caja
    raise HTTPException(status_code=401, detail="Token invalido")


def require_admin(
    authorization: Optional[str] = Header(default=None), settings: Settings = Depends(get_settings)
) -> None:
    if not authorization or not authorization.startswith("Bearer "):
        raise HTTPException(status_code=401, detail="Falta token Bearer")
    token = authorization.removeprefix("Bearer ").strip()
    if not settings.tokens.get("ADMIN") or token != settings.tokens["ADMIN"]:
        raise HTTPException(status_code=403, detail="Requiere ADMIN_TOKEN")


def validar_purpose(purpose: Optional[str] = None) -> str:
    if not purpose or purpose not in VALID_PURPOSES:
        raise HTTPException(status_code=400, detail="purpose ausente o invalido")
    return purpose
```

```python
# src/audit.py
import asyncio
from datetime import datetime, timezone
from typing import List

from .documents import mask
from .schemas import AuditEntry, ConsultaResultado


class AuditLog:
    """Registro en memoria de quien consulto, con que finalidad y que resultado
    obtuvo. El documento se guarda siempre enmascarado."""

    def __init__(self) -> None:
        self._entries: List[AuditEntry] = []
        self._lock = asyncio.Lock()

    async def registrar(self, requesting_caja: str, purpose: str, result: ConsultaResultado, document: str) -> None:
        entry = AuditEntry(
            timestamp=datetime.now(timezone.utc).isoformat(),
            requestingCaja=requesting_caja,
            purpose=purpose,
            result=result,
            documentMasked=mask(document),
        )
        async with self._lock:
            self._entries.append(entry)

    async def recientes(self, limit: int = 100) -> List[AuditEntry]:
        async with self._lock:
            return list(self._entries[-limit:])
```

```python
# src/batch.py
import asyncio
import csv
import io
import uuid
from dataclasses import dataclass, field
from datetime import date
from typing import Dict, List, Sequence

from .adapters.base import CajaAdapter
from .orchestrator import consultar_v1
from .schemas import BatchResultItem


@dataclass
class BatchJob:
    job_id: str
    status: str = "PENDING"
    results: List[BatchResultItem] = field(default_factory=list)


class BatchStore:
    """Jobs de lote en memoria, con idempotencia por Idempotency-Key. Vive
    mientras vive el proceso: no se exige persistencia entre reinicios para
    este reto (ver docs/adr/ para la justificacion)."""

    def __init__(self, concurrency: int = 50) -> None:
        self._jobs: Dict[str, BatchJob] = {}
        self._idempotency: Dict[str, str] = {}
        self._lock = asyncio.Lock()
        self._semaphore = asyncio.Semaphore(concurrency)
        self._background_tasks: set = set()

    @staticmethod
    def parse_documents(csv_bytes: bytes) -> List[str]:
        text = csv_bytes.decode("utf-8-sig")
        reader = csv.DictReader(io.StringIO(text))
        if reader.fieldnames is None or "document" not in reader.fieldnames:
            raise ValueError("El CSV debe tener una columna 'document'")
        return [row["document"].strip() for row in reader if row.get("document", "").strip()]

    async def get_or_create(
        self, idempotency_key: str, documents: Sequence[str], requester: str, adapters: Sequence[CajaAdapter]
    ) -> str:
        async with self._lock:
            existing = self._idempotency.get(idempotency_key)
            if existing:
                return existing
            job_id = str(uuid.uuid4())
            self._idempotency[idempotency_key] = job_id
            self._jobs[job_id] = BatchJob(job_id=job_id)

        task = asyncio.create_task(self._run(job_id, documents, requester, adapters))
        self._background_tasks.add(task)
        task.add_done_callback(self._background_tasks.discard)
        return job_id

    async def _run(self, job_id: str, documents: Sequence[str], requester: str, adapters: Sequence[CajaAdapter]) -> None:
        job = self._jobs[job_id]
        job.status = "RUNNING"
        today = date.today()

        async def procesar(document: str) -> BatchResultItem:
            async with self._semaphore:
                respuesta = await consultar_v1(document, requester, adapters, today)
            return BatchResultItem(
                document=document, result=respuesta.result, matches=respuesta.matches, unavailable=respuesta.unavailable
            )

        job.results = await asyncio.gather(*(procesar(d) for d in documents))
        job.status = "DONE"

    def get(self, job_id: str):
        return self._jobs.get(job_id)
```

```markdown
# ADR 001: Patron de integracion hub central

## Contexto

El reto exige integrar cuatro cajas heterogeneas (REST, SOAP, archivo plano, y una
cuarta activable por configuracion) detras de un unico contrato ya fijado por los
organizadores. El equipo es de dos personas con tiempo acotado y el contrato no
deja margen para negociar el formato de respuesta entre cajas.

## Decision

Usamos un hub central: un unico servicio (`caja-link`) que mantiene un adaptador
por caja detras de una interfaz comun (`CajaAdapter.lookup`) y un orquestador que
llama a todos los adaptadores relevantes en paralelo, agregando el resultado.

## Alternativas

- Federado: cada caja resuelve su parte de la consulta y las respuestas se
  combinan en el cliente o en un bus de eventos; descartado por requerir que las
  cajas (que son mocks fijos del kit) cooperen en un protocolo que no existe.
- Hibrido: hub central para consulta en linea, cola de eventos para el lote;
  descartado por complejidad operativa (una pieza de infraestructura mas) sin
  beneficio medible a la escala de 4 cajas y 10.000 documentos del reto.

## Consecuencias

Toda la logica de negocio (exclusion de la caja consultante, calculo de vigencia,
tolerancia a fallas) vive en un solo lugar (`src/orchestrator.py`), facil de
probar con adaptadores falsos sin red. El costo es que el hub es un punto unico
de fallo del lado de caja-link mismo, aceptable porque el propio contrato del
reto ya asume un unico servicio en el puerto 8083.
```

```markdown
olvidar filtrar un campo nuevo que se agregue despues.

## Decision

Los modelos de respuesta (`src/schemas.py`) se construyen campo por campo a
partir del resultado interno del adaptador (`CajaLookup`/`Membership`), nunca
por "spread" o reenvio del diccionario crudo de una caja.

## Alternativas

- Lista negra de campos a remover antes de responder: descartada porque un
  campo nuevo que una caja agregue en el futuro pasaria por defecto, al reves
  de lo que exige la ley (solo se comparte lo explicitamente necesario).
- Serializacion automatica del modelo interno de cada caja con un decorador
  de "campos publicos": descartada por ser mas compleja que simplemente no
  tener esos campos en el modelo de respuesta.

## Consecuencias

Es estructuralmente imposible filtrar un campo prohibido por error: el modelo
de respuesta no tiene atributo para ponerlo. El costo es que agregar un campo
legitimo al contrato (p. ej. `affiliateType` en v2) requiere tocar el modelo de
respuesta explicitamente, lo cual es deseable para este caso.
```

```markdown
# Arquitectura

## Contexto

Caja Link resuelve la interoperabilidad entre cuatro cajas de compensacion que
hoy se validan afiliaciones por archivos mensuales o integraciones punto a
punto. El servicio centraliza esa validacion detras de un unico contrato HTTP
en el puerto 8083, consumido por cada caja con su propio token Bearer, de forma
que agregar una quinta caja en el futuro no implique cambiar las integraciones
existentes de las demas.

## Componentes

`src/adapters/` contiene un adaptador por caja (Norte REST, Oriente SOAP,
Centro archivo plano, Sur REST v2), todos implementando `CajaAdapter.lookup`.
`src/orchestrator.py` llama en paralelo a los adaptadores relevantes (todos
menos el de la caja consultante) y agrega el resultado. `src/security.py`
resuelve el token Bearer a la caja que pregunta y valida la finalidad.
`src/batch.py` reutiliza el mismo orquestador para procesar un CSV completo de
forma concurrente y acotada. `src/audit.py` registra cada consulta con el
documento enmascarado. `src/main.py` expone todo como rutas FastAPI.

## Flujo de consulta

Una caja llama `GET /api/v1/affiliations/{documento}?purpose=...` con su token.
El documento se normaliza (sin puntos, espacios ni ceros a la izquierda) y el
orquestador llama en paralelo, con timeout de 2.5 segundos cada uno, a los
adaptadores de las demas cajas. Cada adaptador devuelve sus afiliaciones o
marca la caja como no disponible; el orquestador decide `AFILIADO_OTRA_CAJA` si
alguna coincidencia esta vigente, `NO_AFILIADO` si todas respondieron sin
coincidencia, o `INDETERMINADO` si alguna caja fallo y no hay coincidencia en
las demas. La respuesta se construye campo por campo en un modelo propio, nunca
reenviando el JSON/XML crudo de una caja.

## Manejo de fallas

Ningun adaptador propaga una excepcion hacia el orquestador: un timeout, un
error de red o una respuesta inesperada se traducen siempre en
`CajaLookup(available=False, ...)`, y el orquestador nunca interpreta "no se
pudo consultar" como "no afiliado". El presupuesto de 5 segundos del contrato
se cumple ejecutando las llamadas en paralelo con un timeout individual menor
(2.5s), de forma que incluso con una caja lenta o caida el tiempo total de
respuesta no depende de cuantas cajas haya, solo del timeout mas alto alcanzado.

## Alternativas descartadas

- Patron federado (cada caja resuelve su parte y las combina el cliente):
  descartado porque exigiria que las cajas simuladas del kit implementen un
  protocolo de coordinacion que no existe y que el reto no pide.
- Cola de mensajes (Redis/RabbitMQ) para el procesamiento por lote: descartada
  por agregar infraestructura sin necesidad real a la escala de 10.000
  documentos del reto; un semaforo de concurrencia en memoria basta y es mucho
  mas simple de operar y depurar durante el hackathon.
```
